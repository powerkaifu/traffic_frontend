# Vehicle.js - Adjust

## 動畫速度調整 (timeMultiplier)

**位置：** `src/classes/config/trafficConfig.js`

**參數：** `animationConfig.timeMultiplier`

**說明：**

- 控制所有車輛的整體動畫速度
- 數值越小動畫越快，數值越大動畫越慢
- 1.0 = 正常速度
- 0.5 = 兩倍速度（動畫變快）
- 2.0 = 半倍速度（動畫變慢）

**快速切換預設值：**

```javascript
// 在 trafficConfig.js 中，直接修改這行：
timeMultiplier: 1.0, // 改為想要的速度

// 或使用預設值：
timeMultiplier: animationConfig.presets.debug,  // 0.3 快速調試
timeMultiplier: animationConfig.presets.normal, // 1.0 正常速度
timeMultiplier: animationConfig.presets.demo,   // 1.5 演示模式
timeMultiplier: animationConfig.presets.slow,   // 2.0 慢動作
```

**範例調整：**

- 調試時：設為 `0.3` 可快速觀察車輛行為
- 演示時：設為 `1.5` 讓觀眾看清楚車輛動作
- 正常運行：建議設為 `1.0` 標準速度
