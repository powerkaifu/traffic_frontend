# 🎯 車輛間距控制功能使用說明（含南北向修正）

## 概述

現在您可以通過靜態配置來控制車輛之間的間距距離，特別針對南北向車輛排隊問題進行了專門修正！

## 🚨 南北向排隊問題修正

### 修正內容

1. **邊界框計算修正**：南北向車輛使用正確的寬高比例（20×35px 而非 35×20px）
2. **車道檢測優化**：增加南北向車道檢測容錯範圍（30px）
3. **專用距離配置**：南北向車輛使用 `northSouthDistanceMultiplier = 0.8` 的專用倍數
4. **詳細調試信息**：增加南北向車輛的距離檢測日誌

### 新增配置

```javascript
class Vehicle {
  static distanceMultiplier = 1.0 // 整體間距控制
  static northSouthDistanceMultiplier = 0.8 // 南北向專用間距控制
  static baseStopDistance = { justStarted: 5, normal: 10 }
  static baseSafeDistance = { justStarted: 8, normal: 15 }
}
```

## 使用方法

### 1. 瀏覽器控制台調用

```javascript
// 設置整體間距
setVehicleDistance(1.5)

// 專門調整南北向間距（解決排隊問題）
setNorthSouthDistance(0.6) // 更緊密排隊
setNorthSouthDistance(1.2) // 更寬鬆排隊

// 查看詳細配置
getVehicleDistanceConfig()
```

### 2. 程式碼中調用

```javascript
// 整體間距
Vehicle.setDistanceMultiplier(1.5)

// 南北向專用間距
Vehicle.setNorthSouthDistanceMultiplier(0.8)
```

## 實際距離計算

### 東西向車輛

```javascript
實際距離 = 基礎距離 × distanceMultiplier
```

### 南北向車輛（🎯 修正重點）

```javascript
實際距離 = 基礎距離 × distanceMultiplier × northSouthDistanceMultiplier
```

## 南北向問題解決方案

### 問題 1：車輛重疊緊貼

**原因**：邊界框計算錯誤（35×20 應為 20×35）
**解決**：修正 `getVehicleConfig()` 中南北向車輛尺寸

### 問題 2：車輛間距過大

**原因**：距離檢測容錯範圍太小（25px）
**解決**：增加為 30px 並加入專用距離倍數

### 問題 3：車道判斷失效

**原因**：X軸偏差檢測不夠精確
**解決**：優化車道檢測邏輯並增加調試信息

### 技術實現

#### 距離計算邏輯

```javascript
// 動態計算實際使用的距離
const baseStopDist = isJustStartedMoving ? Vehicle.baseStopDistance.justStarted : Vehicle.baseStopDistance.normal

// 南北向車輛會額外乘以 northSouthDistanceMultiplier
const actualStopDistance =
  baseStopDist * Vehicle.distanceMultiplier * (isNorthSouth ? Vehicle.northSouthDistanceMultiplier : 1.0)
```

#### 統一配置

所有距離相關的計算都使用統一的配置：

- `performDetailedCollisionCheck()` - 碰撞檢測
- `moveAlongPath()` - 移動路徑中的速度控制
- `calculateFollowingSpeed()` - 跟車速度計算

這確保了整個系統的一致性，避免了不同模組使用不同間距標準的問題！
