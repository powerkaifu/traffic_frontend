## 🎯 三階段優化詳解

### 第 1 階段：SpatialHashGrid (空間分割)

**原理**:
```
場景分成 8×6 網格
每個格子記錄車輛列表
查詢時只檢查相鄰格子 (3×3)
而不是檢查全部 100 台車

結果: O(100) 搜索 → O(3-5) 搜索 = -95-97% 計算
```

**文件**:
- ✅ 新建 `src/classes/optimization/SpatialHashGrid.js`
- ✅ 修改 `CollisionController.js` 使用網格
- ✅ 修改 `IndexPage.vue` 初始化網格
- ✅ 修改 `Vehicle.js` 每幀重建網格

### 第 2 階段：前車緩存 (Cache)

**原理**:
```
記住前方最近的車
100ms 才更新一次緩存
中間 99ms 直接使用緩存結果

結果: 前車搜索從 60Hz 降至 10Hz
每秒減少 3590 次搜索 (從 3600 → 10)
```

**文件**:
- ✅ 修改 `CollisionController.js` 添加緩存邏輯

### 第 3 階段：黃燈決策降頻 (Throttle)

**原理**:
```
黃燈決策從 60Hz 改為 20Hz
每 50ms 計算一次
中間 3 幀使用上次的決策結果

結果: 決策計算從 3600/秒 → 1200/秒
用戶體驗無變化 (視覺上仍然平滑)
```

**文件**:
- ✅ 修改 `Vehicle.js` 添加決策緩存
